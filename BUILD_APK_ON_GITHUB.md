# Build the APK on GitHub (no Android Studio needed)

1. Create a new GitHub repository.
2. Upload all files and folders from this project, including the hidden `.github` folder.
3. Open the repository's **Actions** tab.
4. Open **Build Pocket Player APK**.
5. Tap **Run workflow**.
6. When the run finishes, open it and download the artifact named **PocketPlayer-debug-apk**.
7. Extract it to get `app-debug.apk` and install it on your Android phone.

Android may ask you to allow installation from your browser/files app. The app itself will ask for video access permission when opened.
